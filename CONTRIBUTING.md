# Contributing to ClickNick

Bug reports are the most useful thing you can send. ClickNick works beside CLICK Programming Software, and the combinations of CLICK version, Office version, and Access driver are more than one person can test.

## Report a bug

Open an [issue](https://github.com/ssweber/clicknick/issues/new/choose). In ClickNick, go to **Help > About ClickNick** and click **Copy System Info**; paste that into the issue. It carries the ClickNick, pyrung, Python, Windows, and Access driver versions. Add your CLICK Programming Software version; ClickNick can't read that.

## Ask a question or share an idea

Use [Discussions](https://github.com/ssweber/clicknick/discussions).

## Change the code

See [development.md](development.md) for setup with `uv` and `make`, and [TESTING.md](TESTING.md) for the manual checklist that covers the Address Editor.

Open a pull request against `main`. Keep it to one change. Use a [Conventional Commits](https://www.conventionalcommits.org/) title such as `fix(workspace): ...` or `docs: ...`, and add one line to `CHANGELOG.md` under Unreleased if the change is visible to users.
