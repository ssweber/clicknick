# Stop memorizing addresses

**Tour 1 of 6**

You type `C123` because CLICK's instruction dialogs don't take nicknames.

![ClickNick nickname autocomplete](https://github.com/user-attachments/assets/3a1cdff9-c425-46b7-8b90-4a357d43b6d3)

Productivity and Do-more autocomplete nicknames as you type. CLICK doesn't, so ClickNick adds it to CLICK's instruction dialogs: start typing the tag you mean, pick a result, and ClickNick inserts the address. The list only offers what the field accepts: bits in a contact, registers in a Compare.

And better than either, ClickNick has smart filters. Match by prefix when your naming is predictable, by any part of the name when you remember only a piece of it, or by abbreviation for names like `Motor_Speed`. Type `Alm1.id` and it reaches `Alm1_id`. SC and SD system addresses and `__private__` tags can be kept out of the list. Hover a result to see its comment.

When the nickname list itself needs work, ClickNick has more: bulk editing, an outline view of your tags, and Data Views built by name.
